# Yanstore Game Images

Upload the nine WebP images included in `yanstore-game-images.zip` to this folder using GitHub's **Add file > Upload files**. Filenames: ml.webp, ff.webp, pubg.webp, genshin.webp, valorant.webp, hok.webp, roblox.webp, hsr.webp, fc.webp.

Until images are uploaded, the website automatically shows emoji placeholders instead.
